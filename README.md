# Chordflow

MVP-конструктор аккордов и гитарного боя на чистом HTML/CSS/JavaScript.

Для запуска из-за ES-модулей откройте папку через любой локальный статический сервер, например:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080/`.

Для телефона подключите Mac и телефон к одной Wi-Fi сети. После запуска откройте на телефоне адрес, который напечатает `start.command`, например `http://192.168.1.25:8080`. Отдельно включать мобильный режим не нужно: сайт сам адаптирует интерфейс под ширину экрана.

Чтобы перенести мелодию на другое устройство, нажмите в приложении «Сохранить», задайте название и передайте скачанный файл `.chordflow.json` на другое устройство. Там откройте сайт, нажмите «Открыть» и выберите этот файл.

Также можно запустить файл `start.command` из Finder или выполнить его в терминале Codex.
